# 大会カレンダーメーカー

カードショップ向けの大会スケジュール画像を、ブラウザ上で作るWebアプリです。月を選ぶと日本の祝日つきのカレンダーが開き、セルをクリックしてイベント・タグ・定休日を編集できます。内容はPostgreSQLに保存されるので、作業を中断しても別の端末から続きを確認できます。

ショップロゴは `public/brand/logo.png` に置くと、黒帯ヘッダー右側とPNG書き出しに合成されます。

## できること

- 対象月を入力すると、その月のカレンダーを自動生成
- 日本の祝日を `holiday_jp` で判定し、日付を赤くする（1日単位の上書きも可）
- セルをクリックしてイベント編集（開始時刻・タイトル・タグ）
- タグの追加・色変更・削除
- 曜日指定の定休日、および「定休日 / 振替休日」などの休みラベル
- セル内容のコピー＆ペースト（ボタン、または ⌘/Ctrl + C / V）
- 長いイベント名を長体（横方向の圧縮）でセル内に収める
- PNG書き出し
- 自動保存（変更の約1.2秒後）と手動保存

## ローカル起動

Ruby 3.3 と PostgreSQL が必要です。

```bash
bundle install
bin/rails db:prepare
bin/rails db:seed
bin/rails server
```

http://localhost:3000 を開きます。

## Railway へのデプロイ

1. このリポジトリを Railway に接続する
2. PostgreSQL プラグインを追加する（`DATABASE_URL` が自動で入ります）
3. 次の環境変数を設定する

| 変数 | 内容 |
| --- | --- |
| `RAILS_MASTER_KEY` | ローカルの `config/master.key` の値 |
| `RAILS_ENV` | `production` |
| `APP_USERNAME` | 任意。Basic認証のユーザー名（未設定時は `admin`） |
| `APP_PASSWORD` | 任意。設定すると画面全体がBasic認証付きになります |

4. Dockerfile でビルドされます。起動時に `db:prepare` が走ります
5. 初回はタグ初期データを入れるため、Railway のコンソールで `bin/rails db:seed` を一度実行するか、エディタを開いた時点でデフォルトタグが自動作成されます

カスタムドメインを使う場合、必要なら `RAILS_ALLOWED_HOSTS` にホスト名をカンマ区切りで入れてください。未設定ならホスト制限は無効です。

## 使い方の目安

1. 一覧で月を選んで「新規作成」
2. 左ペインでタイトル、定休日の曜日、日付カラーを設定
3. 日付をクリックしてイベントを追加。タグは左ペインで管理
4. 「この日をコピー」のあと、別の日付を選んで「貼り付け」
5. 「PNG書き出し」で画像を保存。ロゴは `public/brand/logo.png` に置くとヘッダーに合成されます
